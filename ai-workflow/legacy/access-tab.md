# Access tab

## Introduction

The **Access** tab on the integration card appears for all integrations included in the Unused Access report. This is where you can investigate the integration by viewing all its data and access on a single page. Here’s what you see:

`[SCREENSHOT: the Access tab on an integration card - information panel, access summary, grant graph, and grant table]`

You can either directly access the **Access** tab from the Unused Access report itself or indirectly, where you can open an integration’s integration card (such as from the **Access Center** or the **Integration Inventory**) and select the **Access** tab.

Learn more about the **Access** tab:

* [About the Access tab]([CHILD URL: About the Access tab]): Review the integration information panel, access summary, grant graph, and grant table, and learn about remediation advice.
* [Access tab reference]([CHILD URL: Access tab reference]): Understand access grant inheritance, categories, scopes, usage calculations, and how remediation recommendations are determined.

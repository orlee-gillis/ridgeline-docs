# API Reference: Unauthorized Agent Access Detection

## `GET /api/list_ai_identities`

**Description:**  
Enumerate all AI identities (agents, service accounts, model deployments) that Ridgeline tracks in your environment. Use this to understand what agents are running and to obtain identity_ids needed for other API calls.

---

## Request

**Method:** `GET`  
**Path:** `/api/list_ai_identities`

**Parameters:**

| Name | Type | Location | Required | Default | Description |
|------|------|----------|----------|---------|-------------|
| `environment` | string | query | no | `"production"` | Filter by environment (e.g., production, staging, development) |
| `identity_type` | string | query | no | — | Filter by type: "agent", "service_account", or "model_deployment" |

**Authentication:** Bearer token in Authorization header

---

## Response

### Success Response (HTTP 200)

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `identity_id` | string | no | Unique UUID identifying this AI identity |
| `identity_name` | string | no | Human-readable name (e.g., "prod-infra-bot") |
| `identity_type` | string | no | One of: "agent", "service_account", "model_deployment" |
| `environment` | string | no | Environment this identity operates in |
| `created_at` | ISO 8601 datetime | no | When this identity was registered |
| `last_activity` | ISO 8601 datetime | yes | Most recent tool call timestamp; null if never called tools |
| `status` | string | no | One of: "active", "inactive", "suspended" |

**Response body example:**

    "status": "active"

    "identity_name": "data-sync-service",
    "identity_type": "service_account",

## Notes

- **Empty results:** Returns empty array `[]` if no identities match filters (not null)
- **Null last_activity:** Indicates identity has never called any tools
- **Inactive status:** Does not prevent the identity from calling tools; only a classification based on 90-day activity threshold
- **Related endpoints:**

  - `GET /api/get_unauthorized_access` — see what an identity actually called outside scope

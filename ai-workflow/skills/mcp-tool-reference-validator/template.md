## `list_ai_identities`

**Purpose:**  
Enumerate all AI identities (agents, service accounts, model deployments) that Ridgeline tracks in your environment. Use this to understand what agents are running and when you need the identity_id for other tools like `get_declared_scope` or `get_actual_access`.

---

**Parameters:**

- **`environment`** (string, optional, default `"production"`)  
  Filter results to a specific environment (e.g., production, staging, development).  
  Constraint: Only environments you have access to will be returned. Attempting to list a restricted environment returns HTTP 403 Forbidden.

- **`identity_type`** (string, optional, no default)  
  Filter to specific identity types: "agent", "service_account", or "model_deployment".  
  Constraint: If not specified, returns all types. Values are case-insensitive.

---

**Returns:**

An array of identity objects, each with:

- **`identity_id`** (string)  
  Unique UUID identifying this AI identity. Use this with `get_declared_scope`, `get_actual_access`, and `get_unauthorized_access`.

- **`identity_name`** (string)  
  Human-readable name for the identity (e.g., "prod-infra-bot").

- **`identity_type`** ("agent" | "service_account" | "model_deployment")  
  The category of this identity.

- **`environment`** (string)  
  The environment this identity operates in.

- **`created_at`** (string, ISO 8601 datetime)  
  When this identity was first registered with Ridgeline.

- **`last_activity`** (string, ISO 8601 datetime, can be null)  
  The timestamp of the most recent tool call. Null if the identity has never called any tools.

- **`status`** ("active" | "inactive" | "suspended")  
  Current operational state. "inactive" means no calls in the last 90 days; "suspended" means manually disabled.

---

**Example response:**

```json
[
  {
    "identity_id": "id_prod-infra-bot-001",
    "identity_name": "prod-infra-bot",
    "identity_type": "agent",
    "environment": "production",
    "created_at": "2026-01-15T10:30:00Z",
    "last_activity": "2026-08-23T14:22:15Z",
    "status": "active"
  },
  {
    "identity_id": "id_svc-account-data-sync",
    "identity_name": "data-sync-service",
    "identity_type": "service_account",
    "environment": "staging",
    "created_at": "2026-03-20T08:00:00Z",
    "last_activity": null,
    "status": "inactive"
  }
]
```

---

**Notes:**

- **Empty results:** Returns empty array [] if no identities match the filters, not null.
- **Null last_activity:** Indicates the identity is registered but has never called any tools. This is expected for new identities or test accounts.
- **status: "inactive"** does not prevent the identity from calling tools; it's only a classification based on activity in the last 90 days. To prevent calls, set status to "suspended" (not exposed via this tool; done via admin console).
- **Access control:** You only see identities in environments you have permission to view. Attempting to list a restricted environment returns HTTP 403 with message "Access denied to environment [name]".
- **Pagination:** Not yet supported. Current limit is 1000 identities per call. If you have more, contact support.

This page describes the columns available on the Overprivileged Roles screen.

## Columns

| Column | What it shows |
| --- | --- |
| Role name | The role's identifier |
| Permission count | Number of permissions attached to the role |
| Last used | When the role was last assumed |

## Filters and views

Filter by permission count or last-used date. Sort any column by clicking its header.

## Overview

Overprivileged Roles is part of the Access Center. It surfaces IAM roles that may have more
permissions than they use.

## Data freshness

Data refreshes daily.

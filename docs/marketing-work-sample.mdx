This work sample covers three marketing pieces for the Unused Access feature. For each one, the AI
draft appears exactly as it was generated, untouched, next to my edited version. A summary under
each pair explains what I changed and why, so the edits show the editorial judgment behind them.

## What is the Unused Access feature?

Unused Access is a feature of Ridgeline, a fictional cloud security product. It finds connected
integrations, including service accounts, that hold access they were granted but never use, and
recommends narrower access that keeps each integration working. Findings are ordered by how much
of the environment each integration can reach, so security teams can decide where to reduce access
first. For the product documentation, see [Unused Access report](unused-access-report.md).

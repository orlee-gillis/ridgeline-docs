This page shows three marketing pieces for the Unused Access feature. For each one, the AI draft
appears exactly as it was generated, untouched, next to my edited version. The notes under each
pair explain what I changed and why, so the edits show the editorial judgment behind them.

:::info[What is Ridgeline Docs and the Unused Access feature?]

**Ridgeline Docs** is this site: customer documentation for Ridgeline, a fictional cloud security
product. It is a portfolio artifact that demonstrates a complete docs-as-code pipeline - Markdown
source in Git, pull-request review, CI quality gates, and automated deployment to GitHub Pages.

**Unused Access** is a Ridgeline feature. It finds connected integrations, including service
accounts, that hold access they were granted but never use, and recommends narrower access that
keeps each integration working. Findings are ordered by how much of the environment each
integration can reach, so security teams can decide where to reduce access first. For the product
documentation, see [Unused Access report](unused-access-report.md).

:::
